# insightoh_web

The official web platform for **InsightOh** — a company that delivers modern web applications and digital products.

---

## Overview

`insightoh_web` is the primary web presence for InsightOh, built as a fullstack application to showcase and deliver our suite of web applications and products. It serves as the foundation for client-facing interfaces, internal tooling, and product delivery.
